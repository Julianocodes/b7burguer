# B7 Burger

Landing page de uma hamburgueria fictícia, com cabeçalho, seção de destaque, busca por categoria e vitrine de produtos. Feita com HTML e CSS puro.

> Projeto desenvolvido acompanhando um curso da **B7Web**, como prática de layout e responsividade.

## Tecnologias

- HTML
- CSS
- Google Fonts (Calistoga e Inter)

## Funcionalidades

- Cabeçalho com logo, menu de navegação e botão "Fazer Pedido"
- Seção de destaque (hero) com imagem e chamada para ação
- Campo de busca e seleção de categoria
- Vitrine de produtos com **CSS Grid** e efeito ao passar o mouse
- Layout responsivo para tablet e celular, com ícone de menu hambúrguer

## O que aprendi

- Montar layouts com **Flexbox** e **CSS Grid**
- Criar versões para telas menores com **media queries**
- Usar fontes do Google Fonts
- Organizar a página em seções semânticas (`header`, `section`, `main`, `footer`)
